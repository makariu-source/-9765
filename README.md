# Strike Zone — браузерный тактический шутер

**Версия 1.2.0** — что нового, см. [CHANGELOG.md](CHANGELOG.md).

Тактический FPS в браузере, вдохновлённый Counter-Strike 2 и Standoff 2: закладка бомбы 5×5, экономика раундов, гранаты, боты с семью уровнями сложности, скрытый MMR и ранги, отдельная лига **PRO League** с ELO, гонка вооружений, бой насмерть, командный бой, тренировка, повторы матчей, управление с клавиатуры/мыши и сенсорного экрана.

Все названия, карты, модели, текстуры и звуки — оригинальные и генерируются кодом (процедурные текстуры на canvas, низкополигональные модели из примитивов, синтез звука WebAudio). Внешних игровых ресурсов нет.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/ (статические файлы, можно выложить на любой хостинг)
npm run preview
```

## Проверки

```bash
npm run typecheck  # TypeScript strict
npm test           # 100+ unit/интеграционных тестов (vitest), включая полные матчи ботов
npm run build && npm run e2e   # браузерный smoke-тест (Playwright/Chromium), скриншоты в tests/e2e/out/
```

Что покрыто тестами (`tests/unit`):

| Файл | Что проверяется |
|---|---|
| `maps.test.ts` | все 9 карт: точки появления, обе точки закладки, достижимость из обеих баз, отсутствие «ловушек», ≥3 маршрутов атаки, позиции защиты, **нет прямой видимости между базами** |
| `game.test.ts` | движение/коллизии/прыжок/присед, урон по зонам и броня, падение урона с дистанцией, пробитие тонких стен, время перезарядки, темп стрельбы, отдача, HE/дым/флешка/молотов, предсказание траектории, установка и взрыв бомбы, разминирование с набором, покупки и лимиты, гонка вооружений, бой насмерть, тренировка, **полный соревновательный матч ботов**, напарники только на A, несколько раундов на каждой карте |
| `fairness.test.ts` | боты не видят сквозь стены и дым, слепнут от флешки, не видят за спиной, реагируют только после времени реакции, не узнают о тихом спрятавшемся противнике, параметры всех уровней в пределах человеческих ограничений, сложность не меняет урон/здоровье/патроны |
| `ratings.test.ts` | Glicko-2, ранги и прогресс, уровни PRO League, ELO с калибровкой и штрафом за выход, таблица лидеров, адаптивный подбор, идемпотентное применение результата, калибровка, «поражение никогда не повышает рейтинг», AFK/подделка результатов, повтор состава, независимость MMR и ELO, сохранение и обнаружение правки профиля |

## Управление

**ПК:** WASD — движение, мышь — обзор, ЛКМ — огонь, ПКМ — прицел (снайперские винтовки) / сильный удар ножом / бросок гранаты снизу, R — перезарядка, Shift — тихий шаг, Ctrl — присед, Space — прыжок, G — граната, E — взаимодействие/разминирование/подобрать, B — магазин, 1–5 — оружие, колесо — смена оружия, F — осмотр, Q — выбросить, X — прошлое оружие, Tab — таблица, Esc — пауза. Все клавиши переназначаются в настройках.

**Телефон/планшет:** плавающий джойстик слева, обзор свайпом справа (и с кнопки огня), кнопки огня (две), прицела, прыжка, приседа, перезарядки, смены оружия, гранат, взаимодействия, магазина, таблицы, шага. Размер, прозрачность и расположение кнопок настраиваются (в игре: Пауза → «Настроить сенсорные кнопки»). Схема определяется автоматически; на ПК сенсорные кнопки не показываются. Помощь в прицеливании для сенсора — только вне рейтинговых режимов.

## Что реализовано

### Игровой процесс
- Фиксированный шаг симуляции 64 тика/с, отделённый от частоты кадров, интерполяция отрисовки.
- Движение в духе CS: ускорение/трение, стрейфы в воздухе, прыжок, присед (в т.ч. в прыжке), ступени и пандусы, урон от падения, замедление от попаданий.
- Стрельба: разброс (стоя/присед/движение/прыжок/очередь), детерминированные паттерны отдачи, удар отдачи в камере, пробитие тонких препятствий с потерей урона, падение урона с дистанцией, хитбоксы головы/груди/живота/ног, броня и шлем, дробь, оптика с уровнями зума и пере-прицеливанием после выстрела, нож со стабами в спину.
- 24 предмета: 5 пистолетов (включая учебный), 3 ПП, 4 винтовки, 2 снайперские, 2 дробовика, пулемёт, нож, золотой нож, 5 гранат, C4. Характеристики едины для людей и ботов.
- Гранаты с физикой и отскоками: осколочная (урон по расстоянию, блокируется стенами), светошумовая (зависит от угла взгляда и дистанции, звон в ушах), дымовая (объёмное облако, блокирует обзор людям и ботам, гасит огонь), зажигательная (зона огня, боты её обходят), приманка (стрельба, неотличимая на слух — в том числе для ботов).
- Бомба: установка 3,2 с только на точке, таймер 40 с с ускоряющимся писком, разминирование 10/5 с, выпадение при смерти и подбор.
- Экономика CS: награды за раунд и убийства по оружию, бонус за поражения с уменьшением после побед, бонус за установку, штраф за убийство союзника, лимит $16 000, зона и время закупки.
- Одновременное разрешение смертей в пределах тика (обмен убийствами честный, без преимущества порядка обработки).

### Режимы
Соревновательный (MR12 или короткий MR8, смена сторон, ничья возможна), обычный (без рейтинга, бесплатная броня), напарники 2×2 (одна точка, свой рейтинг), PRO League (овертаймы MR3), бой насмерть (FFA, выбор оружия, защита при возрождении, очки), командный бой насмерть, гонка вооружений (настраиваемая лестница, понижение ножом, финал — золотой нож), тренировка (манекены, движущиеся цели со скоростью/направлением, тест реакции, стена отдачи, гранаты с бесконечным запасом), пользовательские матчи (любой режим/карта/размер команд/сложность), **наблюдение за ботами** (матч только из ботов: выбор карты, количества и сложности каждой команды, камеры «авто / за бойцом / глазами / карта», подписи с ролью и намерением каждого бота), еженедельные испытания.

### Карты (9 + полигон)
Sandstorm (по мотивам Dust II), Oasis (Mirage), Villa (Inferno), Reactor (Nuke, подземная точка B и вентиляция), Ruins (Ancient), Canal (Overpass), Skyline (Vertigo), Depot (Train), Pharaoh (Anubis). Карты описываются DSL на сетке; из одного источника строятся коллизии, навигация, мини-карта и меши — что видно, то и сталкивается. Автоматический анализ карты находит маршруты атаки, точки ожидания вне видимости точки, позиции защиты и места закладки.

### Боты
- Восприятие — единственный источник информации о противнике: поле зрения, прямая видимость (стены, дым), ослепление, время реакции, слух с погрешностью, память, передача информации союзникам с задержкой. Тест `fairness.test.ts` подтверждает отсутствие «волхака».
- Индивидуальное поведение: навигация по сетке с обходом дыма и огня, сглаживание пути, выход из застревания, бой с настройкой ошибки прицела, «дрожанием», упреждением, контролем отдачи, контр-стрейфом, дисциплиной очередей, присед при стрельбе на дистанции; не стреляют через союзников; перезарядка в безопасный момент, смена на пистолет, отступление, отход при численном меньшинстве; предугадывание места появления услышанного врага; отворачиваются от летящей флешки; подбор оружия по ценности и ситуации (длина простреливаемых линий, остаток патронов, только когда безопасно) и подбор бомбы.
- Командная игра: решения по экономике (полная закупка/форс/эко), выбор точки с адаптацией по истории раундов, планы «раш/выполнение/сплит/дефолт», разведка и смена точки, расстановка защиты с перекосом в сторону любимой точки соперника и сменой позиций от раунда к раунду и посреди раунда, роли «выход вперёд», «роумер», «обход в тыл» у защиты и «лёркер», «обход» у атаки (чаще на высокой сложности), ротации по информации, сбор перед ретейком, позиции после установки, гранаты с расчётом траектории физикой (дым на кросс, флешка перед заходом, молотов на позицию, HE по услышанным).
- 7 уровней сложности: Новичок … Профессиональный. Уровень меняет только качество решений (реакция, ошибка прицела, скорость поворота, дисциплина, тактика, гранаты, адаптация), но никогда урон, здоровье, патроны или информацию.

### Рейтинги
- **Скрытый MMR** — Glicko-2 (неопределённость для новичков), сила соперника учитывает силу ваших союзников. Знак изменения определяется только исходом; разница счёта и личная игра влияют на величину. **Видимые очки ранга** плавно сходятся к MMR. 10 калибровочных матчей. 22 ранга от «Новичок I» до «Легенда» с SVG-эмблемами, прогрессом, историей и анимацией повышения; пороги настраиваются и фиксированы (высший ранг всегда достижим).
- **PRO League** — независимый ELO: калибровка 5 матчей (K=50), далее K=32, уровни 1–10 по настраиваемым диапазонам, сезоны по 8 недель, таблица лидеров (участники-боты помечены «ИИ», с профилями), строгий подбор (±50 ELO, медленное расширение окна), очередь поиска, вето карт, штраф за выход (−50 ELO и растущий запрет поиска). Сила ботов растёт с уровнем: 1–3 базовые, 4–6 опытные, 7–8 элитные, 9–10 максимальные тактические.
- **Адаптивный подбор**: цель = рейтинг + поправка на серию и форму, меняется не более чем на 50 за матч; противники вокруг цели, союзники подбираются так, чтобы средние силы команд совпадали. Исход не гарантируется и не подкручивается.
- **Честность**: результат применяется один раз (по matchId), журнал изменений рейтинга только дополняется (с причинами), AFK / массовые убийства союзников / неучастие / неправдоподобная статистика не дают роста рейтинга, повтор одинакового состава даёт половину изменения, выход — поражение и ограничение поиска, контрольная сумма профиля выявляет ручную правку localStorage.

### Клиент
Three.js: карты с мировыми UV и объединением геометрии по материалам, солнечные тени, туман, небо; шарнирные модели бойцов (8 вариантов) с процедурной анимацией ходьбы/бега/приседа/прыжка/стрельбы/перезарядки/броска/установки/разминирования/смерти; вид от первого лица отдельным проходом (руки, доставание, покачивание, отдача, смена магазина, осмотр, бросок, удар ножом, набор кода C4); эффекты с пулами объектов (трассеры, инстанс-декали, искры, кровь, вспышки, взрывы, дым из спрайтов, огонь). HUD: здоровье/броня/деньги/патроны/гранаты, динамический прицел, индикаторы попаданий и направления урона, лента убийств, радио-сообщения ботов, мини-карта (союзники и замеченные враги), таймер и счёт, полоса установки/разминирования, оптика, ослепление, наблюдение после смерти. Магазин, таблица игроков, пауза, послематчевый экран с отчётом о сильных и слабых сторонах, повтор матча со свободной/следящей камерой и перемоткой.

## Архитектура

```
src/sim/       — симуляция без зависимостей от рендера (запускается в Node для тестов)
  maps/        — DSL карт, компиляция сетки, 9 карт + полигон
  world.ts     — коллизионный мир, broadphase, лучи, пробитие, движение тела
  nav.ts       — навигационная сетка, A*, поля расстояний, тактический анализ карты
  game.ts      — игровой цикл, оружие, баллистика, гранаты, бомба, подбор
  modes/       — режимы (bomb, respawn, training), результат матча
  buy.ts, weapons.ts, grenades.ts, replay.ts
src/ai/        — восприятие, бот, командный мозг, сложность, планирование бросков
src/meta/      — Glicko-2, ранги, PRO League, подбор, профиль/хранилище, испытания, отчёт
src/match.ts   — сборка матча из лобби (общая для клиента и тестов)
src/client/    — рендер (Three.js), звук (WebAudio), ввод, UI, сессия матча
```

Игрок и боты управляют персонажами одинаково — через структуру `InputCmd`, поэтому для ботов нет «особых» правил.

## Ограничения и что дальше

- **Сетевой мультиплеер не реализован.** Все союзники и соперники — боты, это явно показывается в интерфейсе, статистике и таблицах. Архитектура к этому готова (детерминированная симуляция с фиксированным тиком, управление через `InputCmd`, результаты в одной структуре `MatchResult`), но серверная часть с авторитетной проверкой событий, аккаунтами и базой данных — следующий большой этап. Оценка объёма работ — в [docs/NETWORK.md](docs/NETWORK.md).
- Защита локального профиля — обнаружение правки, а не криптографическая защита: владелец устройства может изменить свои локальные данные. Для онлайн-рейтинга проверка должна выполняться на сервере.
- Модели — стилизованная низкополигональная графика из примитивов, а не детализированные модели уровня CS2.
- Баланс сторон измерен матчами ботов (`npm run balance`): по 27 матчам на всех картах атака выигрывает около 55% раундов; Reactor и Villa после правок склоняются к защите (~37% у атаки), остальные карты ближе к 50%. Выборка небольшая, результат одного матча сильно зависит от экономики.
- Шкала сложности проверена «лестницей» (`npm run ladder`): каждый уровень выигрывает у предыдущего 68–82% раундов, разрыв в 3–4 уровня — 27:0.
