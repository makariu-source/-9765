# Сетевая игра: насколько это сложно

Коротко: **это самая большая и дорогая часть проекта** — по объёму сопоставима со всем, что уже сделано. Сейчас игра полностью работает в браузере против ботов; для игры людей между собой нужен сервер.

## Что уже готово и поможет

- Симуляция отделена от графики и работает без браузера (её можно запустить прямо на сервере Node.js).
- Фиксированный шаг 64 тика в секунду — то же самое, что использует сервер.
- Игроки и боты управляют персонажами одной структурой команд `InputCmd` — по сети нужно передавать именно её.
- Результат матча собирается в одну структуру `MatchResult`, рейтинги считаются отдельно — их легко перенести на сервер.

## Что нужно сделать

| Часть | Что это | Сложность |
|---|---|---|
| Игровой сервер | Node.js + WebSocket (или WebRTC), авторитетная симуляция: сервер сам считает движение, выстрелы и урон, клиент только присылает команды | высокая |
| Предсказание на клиенте | Чтобы игра не «тормозила» при пинге 50–150 мс: клиент сразу двигает своего персонажа и потом сверяется с сервером | высокая |
| Интерполяция чужих игроков | Плавное движение других игроков между пакетами сервера | средняя |
| Компенсация задержки (lag compensation) | Сервер «откатывает» позиции на момент выстрела, чтобы попадания засчитывались честно | высокая |
| Сжатие трафика | Дельта-снимки состояния, квантование координат — иначе слишком много данных | средняя |
| Аккаунты и вход | Регистрация, пароли/вход через сервис, защита сессий | средняя |
| База данных | Рейтинги MMR и ELO, история матчей, статистика, PRO League | средняя |
| Матчмейкинг | Очередь, подбор по рейтингу и пингу, регионы, добор ботами | средняя |
| Античит на сервере | Проверка скорости, частоты стрельбы, видимости; рейтинг меняет только сервер | средняя–высокая |
| Хостинг | Серверы в нескольких регионах, мониторинг, обновления без остановки | постоянные расходы |

## Оценка

- **Минимальная версия** (комнаты по ссылке, 2–10 игроков, один регион, без рейтинга): примерно 3–6 недель работы одного опытного разработчика.
- **Полноценная версия** (аккаунты, рейтинговый матчмейкинг, PRO League онлайн, античит, несколько регионов): несколько месяцев и платный хостинг.

## Рекомендуемый порядок

1. Комнаты по ссылке с другом (обычный матч, без рейтинга) — сервер на Node.js с той же симуляцией.
2. Предсказание и интерполяция, проверка на реальном пинге.
3. Аккаунты и база данных, перенос рейтингов на сервер.
4. Матчмейкинг и PRO League онлайн, античит.
